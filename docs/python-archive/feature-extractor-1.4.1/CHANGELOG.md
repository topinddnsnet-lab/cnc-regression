## v1.3.1（2026-09-29）

小更新：垂直線清角（泛用規則）＋深度分層。

### 新增
1. **垂直線清角**：沿料長的中心線走到接觸端（垂直邊界線）後，沿那條垂直線橫掃一趟，
   刀心超出帶子兩側各 r（先往上緣外、再往下緣外）。只在刀緣多掃到的範圍（該層深度內）都是空氣時做，
   例：NTN007 凸緣上的槽兩側是凸緣材料 → 不清角（`compensation.tool_path(clean_ends)`、工序 `details.cornerClean`）。
2. **深度分層**：挖除區塊的斷面寬度隨深度改變時，依深度分層（由上而下），每層各自決定中心線、刀具、清角；
   深度餘量只加在最底層（`faces.depth_layers`）。CJN38：小勾層（z 71～73、寬 -24～-19）與臂層（z 2～71、寬 -24～-22），
   臂層清角到 -17 剛好不碰上方 Z 形的下緣。
3. **從料外進刀**：中心線一律從料外那端進刀，走到接觸端再清角。

## v1.3.0（2026-09-29）

功能新增：新案例 CJN38-32（特徵只畫成隱藏線、端視圖在右邊需鏡射）帶出的五條通用規則。

### 新增規則
1. **料長方向鏡射（使用者規則）**：沒有孔校正的視圖時，斷面來源的端視圖畫在主視圖**右邊**（垂直方向有重疊）
   → 以斷面擠出的工件相對主視圖是鏡射的，x 反向；畫在左邊 → 同向；不在旁邊（例：下方的剖視）→ 沒有證據，照舊。
   （`calibration.end_view_sx`；孔左右不對稱時仍以孔為準。）
2. **幾何校正含隱藏線**：實線與隱藏線都必須落在工件邊上（中心線等不算）。只有外框實線時正面／背面貼合率一樣，
   隱藏線是另一側的邊，能分出是哪一面（`calibration.edge_fit_all`）。
3. **垂直線＋不連續線直接圍出區域（含隱藏線，需求 1）**：外框是完整矩形、灌水進不去時，
   非料長端的垂直線上下範圍內，平行邊線都從它往同一側延伸、另一側沒有 → 那一側到料長端就是特徵（`view_regions._line_regions`，
   區域種類 `edge`，深度方向用斷面剖面線定位）。
4. **刀可以比特徵寬**：只要多掃到的範圍都是空氣（或其他要去掉的區塊），由大到小挑刀、一趟沿中心線走完；
   料外那端外延 r、接觸那端內縮 r（`faces.sweep_clear`、`engine._widen_tool`）。深切自動分次下刀：每次 ≤ 2 × 刀徑
   （工序 `details.deepCount`，後處理優先採用）。
5. **舊規劃與邊界引擎矛盾就不採用**：同一面向、同一條橫向帶，邊界引擎已判定只有哪幾段要去除，
   舊規劃在那條帶上多切超過一個刀徑 → 只留參考（`engine.contradicts_band`）。

### 修正
- 孔投影框（沉頭孔各段畫成的小矩形）：同位置任何一段孔徑對得上就排除，不再只比單一直徑。

## v1.2.0（2026-09-29）

小更新：新增「邊界引擎」並預設採用；輸出檔格式不變（`_ops.json`／`_cnc_project.json` 多了 `source: "boundary"` 與依據欄位）。

### 新增
1. **邊界引擎**（`dxf_feature_extractor/boundary/`），每一步獨立：
   - `view_regions.py`：已校正視圖的實線（含**料長端以外的垂直線**、**不連續線**、圓）當牆，從毛料外灌水，
     灌得進毛料範圍的＝要去掉的區域；每個區域附上圍出它的邊界線當依據。封閉小輪廓另收（孔位專案已有的孔排除）。
   - `evidence.py`：各份斷面圖（剖視、端視）的剖面線換到斷面原始座標，定出封閉特徵在深度方向的位置。
   - `chunks.py`：區域 → 斷面上的連通塊（例：U 形槽的兩隻腳各一塊）。
   - `faces.py`：**象限法**（斷面盒子中心為原點：I＝TOP/FRONT、II＝TOP/BACK、III＝BOTTOM/BACK、IV＝BOTTOM/FRONT）
     定候選面向，再比各面向**實際切到的材料體積**（切斷＝刀寬沿接觸邊掃過；坐在保留材料上只能整塊挖除；
     上方有保留材料＝不可加工），最少者勝；差 10% 以內象限內面向優先、再比下刀距離。
   - `minpath.py`：**最短路徑**（不含刀具）：區塊俯視外框上接觸保留材料的邊串成折線，兩端落在料外；四邊都接觸＝封閉。
   - `compensation.py`：**刀具補正**（與路徑分開）：刀徑 10／6／4 挑放得進去的最大一把；刀心內縮 r、開放端外延 r；
     封閉輪廓寬＝刀徑時退化成中心線。
   - `engine.py`：串起來輸出工序（Z＝切削層頂、深度＝層厚＋1mm 餘量）。
2. **合併策略**：邊界引擎有結果時預設採用；路徑規劃（JS 移植）的工序若 50% 以上落在邊界引擎的區塊裡就只留參考，
   其餘照舊採用（補新引擎沒涵蓋的材料，例：PYN09 底面的長條切斷）；正視圖規則一律參考。
3. **回歸測試框架**（`application/regression.py`、`tools/regress.py`、`tests/test_regression.py`）：
   - 案例放 `tests/fixtures/regression/<案例>/`：`source.dxf`、`expected.json`（人工 v2 shapes）、`case.json`（面向對照、已知人工疑點）。
   - 逐條人工路徑由便宜到貴判定，前一層過就不跑後面：L1 座標（同面向同刀徑同折線）→ L2 面積（刀具掃過面積覆蓋 ≥80%）
     → L3 體積（程式去掉 ≥80%）；全案再看去除體積召回 ≥80%、程式／人工 ≤2。全部 L1 通過時略過全案體積。
   - 面向對照 `auto`：每個人工面向找切得到最多材料的程式標籤（v1.2.1 起只供診斷）。
